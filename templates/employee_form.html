Import Employees from File

Add one employee or several employees at once. Upload only CSV, Excel (.xlsx), or JSON files.

Required for every employee
  • employee_code, name, and department
  • Either role_id or role_title (the existing job-role title)
Optional columns

experience_level, location, joining_date, reporting_manager, required_competencies, prior_experience, and training_status.

Format rules: Use YYYY-MM-DD for joining_date. Use Beginner, Intermediate, or Advanced for experience_level. In CSV and XLSX, separate multiple required_competencies with semicolons. The full file is checked first. If any row has an error, no employee profiles are created.

For CSV or XLSX, use a first-row header such as employee_code,name,role_title,department. For JSON, upload one employee object, an employee array, or an object containing an employees array.
